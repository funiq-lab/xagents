# XAgents

[中文版](./README.md)

**XAgents** is a cross-platform desktop app for centralized management of multiple AI coding tools (VSCode, Cursor, Claude Code, Codex, etc.), including project organization, session tracking, and process monitoring.

## Core Features
- **Centralized Project Management**: Create, edit, and delete projects with support for grouping and tagging. Filter projects using multiple combined conditions.
- **One-Click Tool Launch**: Command-level launch and window-switching logic for VSCode, Cursor, Claude Code, and Codex, avoiding duplicate instances.
- **Real-Time Process Monitoring**: Polling for CPU/memory usage, runtime duration, CLI output, and task progress, with instant updates on abnormal exits.
- **Visual Dashboard**: Display project overviews, active sessions, resource usage, and the latest output summaries in a card view.
- **Notifications and Alerts**: Dual-channel notifications via system alerts and in-app prompts for task completion, failures, and resource warnings.

## Project Goals
1. Reduce the window management overhead for multi-project, multi-tool parallel development.
2. Provide a consistent launch and monitoring experience across macOS, Windows, and Linux.
3. Reserve interfaces for future expansion to support more AI tools and custom rules.
